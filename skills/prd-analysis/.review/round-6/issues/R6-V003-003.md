# check-scripts-inventory.sh REQUIRED_SCRIPTS list omits `check-skill-md-sections.sh` (CR-S15 checker)

## Finding

`scripts/check-scripts-inventory.sh` lines 23–48 hard-code the inventory of scripts that
MUST exist and be executable in `<target>/scripts/`. The list contains 24 scripts. However,
**`check-skill-md-sections.sh` is missing from the list**, even though it is the script that
implements **CR-S15 skill-md-cost-control-sections** in `common/review-criteria.md`.

Specifically, `common/review-criteria.md` lines 147–152 declare:

```yaml
- id: CR-S15
  name: "skill-md-cost-control-sections"
  version: 1.0.0
  checker_type: script
  script_path: scripts/check-skill-md-sections.sh
  severity: error
```

But `scripts/check-scripts-inventory.sh` does not include `"check-skill-md-sections.sh"` in
its REQUIRED_SCRIPTS array. This means CR-S05 (scripts-inventory) cannot enforce the
presence of CR-S15's checker. If a future scaffold or revise round deletes
`check-skill-md-sections.sh`, run-checkers.sh would emit a `CR-META-missing-checker` issue
(via `run-checkers.sh` lines 421–442) but `check-scripts-inventory.sh` itself would
silently report "no inventory issues" — a contradictory pair of signals from the same
review pass.

This violates **CR-L04 (cross-reference consistency between criteria and the inventory
that is supposed to enforce their checker presence)**.

## Suggested fix

Add `"check-skill-md-sections.sh"` to the REQUIRED_SCRIPTS array in
`scripts/check-scripts-inventory.sh`. The addition should be placed alphabetically (after
`check-scaffold-sha.sh`, before `check-artifact-pyramid.sh` if maintaining alpha order) or
at the end of the inventory block to match existing ordering conventions.
