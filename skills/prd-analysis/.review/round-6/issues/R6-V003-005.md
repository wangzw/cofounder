# prune-traces.sh greps `retention_rounds:` but config.yml defines `traces_retention_rounds:` — config-file lookup is dead code

## Finding

`scripts/prune-traces.sh` lines 19–25 attempt to source the retention-rounds value from
`common/config.yml`, falling back to a hard-coded default of 20:

```bash
if [ -z "$RETENTION" ]; then
  CONFIG_FILE="${TARGET}/common/config.yml"
  if [ -f "$CONFIG_FILE" ]; then
    RETENTION=$(grep -E '^\s*retention_rounds\s*:' "$CONFIG_FILE" | head -1 | sed 's/.*:\s*//' | tr -d ' "' || echo "")
  fi
  RETENTION="${RETENTION:-20}"
fi
```

The grep pattern is `retention_rounds:` (without the `traces_` prefix). However,
`common/config.yml` line 67 defines the key as **`traces_retention_rounds:`**:

```yaml
convergence:
  ...
  traces_retention_rounds: 20
```

Therefore the grep never matches, `$RETENTION` always falls through to the hard-coded
default `20`, and any user who edits `traces_retention_rounds:` in `config.yml` to
override the default will see their override silently ignored. This is dead code masking
a real configuration knob.

Cross-reference evidence: `scripts/commit-delivery.sh` lines 86–93 documents the correct
key name in its own comment block:

```bash
# Auto-prune old traces so .review/traces/ doesn't grow unbounded. Retention
# policy lives in common/config.yml (convergence.traces_retention_rounds,
# default 20). prune-traces.sh is a best-effort step ...
```

So the contract is: `convergence.traces_retention_rounds` is the user-facing knob;
`prune-traces.sh` is the consumer. The two are misaligned.

This violates **CR-L04 (cross-reference consistency)**: two leaves in the focus subset
(`prune-traces.sh` and `commit-delivery.sh` / `common/config.yml`) hold contradictory
descriptions of the retention key name.

## Suggested fix

Either rename the grep pattern to match the config key, or — better, since the key is
nested under `convergence:` — use a more precise extractor. Minimal patch:

```bash
RETENTION=$(grep -E '^\s*traces_retention_rounds\s*:' "$CONFIG_FILE" | head -1 | sed 's/.*:\s*//' | tr -d ' "' || echo "")
```

If multiple keys named `traces_retention_rounds` could exist at different nesting depths
(unlikely in practice), additionally restrict to lines indented two spaces (matching the
`convergence:` block).
