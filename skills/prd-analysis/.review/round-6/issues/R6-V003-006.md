# summarizer-subagent.md mislabels commit-delivery.sh's third argument as `<change-summary-slug>`

## Finding

`shared/summarizer-subagent.md` line 234 instructs the summarizer to invoke
`commit-delivery.sh` with this signature:

```bash
../scripts/commit-delivery.sh <target> <delivery-id> <change-summary-slug>
```

But the actual `scripts/commit-delivery.sh` documents and accepts a free-form
**`<change-summary>`** as the third argument; it slugifies the input internally
(`commit-delivery.sh` lines 30–63 contain the slug-derivation Python block, including the
"strip leading redundant `delivery-N:` prefix" rule and the slugify regex). The script's
own header reads:

```
# commit-delivery.sh — §8.3 delivery commit + annotated tag
# Usage: commit-delivery.sh <target-skill-dir> <delivery-id> <change-summary>
```

A summarizer agent that follows the prompt literally will pre-slugify the change summary
(e.g. emit `e2e-regen-skill-forge-final` instead of the human-readable
`E2E regen via skill-forge — final delivery`). The script's slugifier will then run a
second pass on the already-slugged input — yielding the same string for ASCII inputs but
losing the human-readable commit-message body, since `commit-delivery.sh` line 81 uses
the raw `${CHANGE_SUMMARY}` as the commit message body:

```bash
git -C "$TARGET" commit -m "feat(${SKILL_SCOPE}): delivery-${DELIVERY_ID}: ${CHANGE_SUMMARY}"
```

That commit message would read `feat(prd-analysis): delivery-2: e2e-regen-skill-forge-final`
rather than `feat(prd-analysis): delivery-2: E2E regen via skill-forge — final delivery`,
producing CHANGELOG entries with mechanical slugs instead of readable summaries. The
mismatch is a CR-L04 (cross-reference consistency between the summarizer prompt and the
delivery script's argument contract).

This is a `warning`-severity issue (functional drift, not a hard break) — the script
still produces a valid tag and commit, just with degraded human readability.

## Suggested fix

Change line 234 to:

```bash
../scripts/commit-delivery.sh <target> <delivery-id> <change-summary>
```

(removing the `-slug` suffix). Optionally add a one-line note immediately below
clarifying that "commit-delivery.sh slugifies the third argument internally — pass a
human-readable change summary, not a pre-slugged token".
