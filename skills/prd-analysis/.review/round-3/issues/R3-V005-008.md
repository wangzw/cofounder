# R3-V005-008: SKILL.md mode routing table omits .review/ pyramid from Output Structure, making the table and structure block inconsistent

## Finding

The `## Mode Routing` table in SKILL.md (line 19) states that review mode issues are "filed under `.review/round-N/issues/`". SKILL.md `## Core Contract` (line 38) states "`.review/` lives at target root. Pyramid-indexed: `round-<N>/` + `metrics/` + `versions/`". However, the `## Output Structure` code block (lines 54–76) does not include the `.review/` pyramid at all — it shows only `.reviews/REVIEW-*.md` (which is the old/legacy path). A reader who consults only the Output Structure block will not know that `.review/` exists, what its contents are, or that it is the actual transient review output location. The mode routing table and Core Contract claim a `.review/` pyramid; the Output Structure shows `.reviews/` with a flat `REVIEW-*.md` — these three sections are mutually inconsistent.

## Fix

Update the `## Output Structure` code block (lines 73–76) to remove the `.reviews/REVIEW-*.md` entry and add the correct `.review/` pyramid. The last two items in the tree should read:

```
└── .review/                 # Transient — not version-controlled
    ├── state.yml
    ├── traces/
    │   └── round-N/
    │       └── dispatch-log.jsonl
    ├── round-N/
    │   └── issues/
    │       └── I-NNN.md
    ├── metrics/
    └── versions/
```

This makes the Output Structure consistent with the mode routing table (line 19), Core Contract (line 38), and Bootstrap Precheck (line 31).
