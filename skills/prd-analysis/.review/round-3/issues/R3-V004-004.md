`skills/prd-analysis/common/review-criteria.md` includes CR-S15 (`skill-md-cost-control-sections`),
which is a skill-forge meta-criterion that applies to generated SKILL.md files — not to PRD
artifact bundles. This criterion is not referenced by any prd-analysis sub-agent prompt as a
criterion to check against PRD output.

**Offending text (lines 118–154):** The full CR-S15 criterion block is embedded in
`prd-analysis/common/review-criteria.md`, verbatim copied from `skill-forge/common/review-criteria.md`.

**CR-S15 definition:** "The target's `SKILL.md` MUST include the cost-control sections..." —
`applies_to: ["SKILL.md"]`. PRD bundles do not contain a `SKILL.md`.

**Why it fails CR-L03 (review-criteria coverage):** CR-S15 is defined in prd-analysis's
`review-criteria.md` but:
1. The `writer-subagent.md` CR Applicability table (lines 192–211) does not list CR-S15
   for any leaf type — it is never applied by any writer self-review.
2. The `cross-reviewer-subagent.md` Section 9 list does not include CR-S15 — it is never
   evaluated by the cross-reviewer.

A criterion present in `common/review-criteria.md` that is never referenced in any sub-agent
prompt is an unreferenced criterion, violating the CR-L03 "every CR id must be referenced
somewhere" requirement. The criterion either belongs exclusively in `skill-forge/common/review-criteria.md`
(and should be removed from prd-analysis) or it needs to be added to at least one applicability
table with a valid leaf type target.
