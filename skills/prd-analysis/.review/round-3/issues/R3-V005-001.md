# R3-V005-001: Output Structure shows .reviews/REVIEW-*.md but mode routing claims .review/round-N/issues/

## Finding

SKILL.md contains two conflicting output path definitions for review findings. The `## Output Structure` section (lines 74–75) shows `.reviews/REVIEW-*.md` as the artifact produced by the review mode and consumed by revise mode. However, the `## Mode Routing` table (line 19) states that review issues are filed under `.review/round-N/issues/` — a completely different directory name (`.review/` without trailing `s`) and a completely different file structure (per-issue `.md` files under `round-N/issues/` vs. a single monolithic `REVIEW-*.md`). This inconsistency means the Output Structure section does not match the actual file routing behaviour documented in the mode routing table.

## Fix

Update the `## Output Structure` code block (lines 73–76) to replace `.reviews/REVIEW-*.md` with the canonical `.review/` pyramid structure. The block should read:

```
└── .review/                 # Transient — not version-controlled
    ├── round-N/
    │   └── issues/
    │       └── I-NNN.md
    ├── metrics/
    └── versions/
```

Remove the `.reviews/` entry entirely from the Output Structure block, as it refers to a legacy mechanism superseded by the `.review/round-N/issues/` structure.
