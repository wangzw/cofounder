# R3-V005-004: SKILL.md Core Contract forbids orchestrator reading artifact leaves but review-mode instructs main agent to read them

## Finding

SKILL.md `## Core Contract` (line 35) declares: "Orchestrator is **pure dispatch + bookkeeping only**. Forbidden: reading artifact leaves." The `## Forbidden Actions` (lines 195–198) section also lists "Reading artifact leaves — no reading of `<artifact-path>` content; those paths belong to sub-agents." However, `review-mode.md` Step 1 (line 55) instructs the "main agent" to read `README.md`, `REVISIONS.md`, and `architecture.md`. Step 4 (lines 173–183) instructs the main agent to run cross-file checks and perform "targeted reads of specific files only when a cross-file finding requires it." These direct reads of PRD artifact leaves by the orchestrator (main agent) contradict SKILL.md's own Core Contract and Forbidden Actions list, creating an irreconcilable conflict within the skill.

## Fix

Either (A) update SKILL.md Core Contract to carve out an explicit exception for the review-mode orchestrator (since prd-analysis uses a Document variant where the orchestrator has direct read access during inventory), or (B) delegate the Step 1 inventory read and Step 4 cross-file checks to a subagent and have the main agent consume only the compact summary.

The preferred fix is (A): add a note to SKILL.md Core Contract that reads: "**Exception for review-mode Step 1 and Step 4:** The main agent MAY read `README.md`, `REVISIONS.md`, and `architecture.md` (the index file) during inventory — these are index/navigation files, not per-feature or per-journey artifact leaves. The main agent MAY perform targeted reads of single feature or journey files when a cross-file check requires spot-verification. It MUST NOT bulk-read the full feature/journey set."
