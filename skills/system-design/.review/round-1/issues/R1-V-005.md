# CR-L11

from-scratch.md Step 8 references `readme-template.md` while the actual template is `design-readme-template.md`

## Reasoning

`SKILL.md` "Configuration & Subagent Files" lists three templates:
- `common/templates/design-readme-template.md`
- `common/templates/module-template.md`
- `common/templates/api-template.md`

`generate/from-scratch.md` Step 8 (Writer Fan-out) lists the templates each writer reads as:
> "Corresponding template from `common/templates/` (determined by target file type: `module-template.md`, `api-template.md`, or `readme-template.md`)"

`readme-template.md` does not exist; the file is `design-readme-template.md`. A writer dispatched for the README leaf will receive a path that does not resolve. This is the same class of CR-L11 path-drift as R1-V-004 — a second instance found via class-based scan.

`generate/writer-subagent.md` Leaf Type 3 also says:
> "`common/templates/design-readme-template.md` — structural scaffold"

So the writer prompt is correct; only `from-scratch.md` Step 8 carries the stale name.

## Suggested Fix

Update Step 8 in `from-scratch.md` to read `design-readme-template.md` instead of `readme-template.md`. Grep the remaining tree for any other occurrence of `readme-template.md` without the `design-` prefix and update consistently.
