- **Detection algorithm — set A (module Deps)**: PASS — For each `M-*.md`
  the caller ID is extracted from the filename via `grep -Eo '^M-[0-9]+'`.
  The Deps section is captured by awk matching headings:
  `## Dependencies`, `## Module Deps`, `## Deps`, `## Deps (direct)`,
  `## Internal (modules)`. All M-NNN tokens in that section (until the next
  `##` heading) are extracted; the caller itself is excluded. The resulting
  `(caller_id, callee_id)` pairs populate set A.

- **Detection algorithm — set B (README Protocols)**: PASS — The
  `## Module Interaction Protocols` section is extracted with awk; table data
  rows are parsed by awk field splitting on `|` to get the "Caller → Callee"
  cell (column 2). The first M-NNN before `→`/`->` is the caller; the first
  M-NNN after the separator is the callee. Header rows (containing "Caller")
  and separator rows (cells of dashes/colons) are skipped. Pairs populate set B.

- **Bidirectional coverage**: PASS — Both (A − B) and (B − A) are computed.
  A−B: dep declared in module but no README row → `A_not_B` direction.
  B−A: README row exists but no module declares the dep → `B_not_A` direction.
  Each missing pair emits its own LINT-NNN.md with direction-specific reasoning
  and suggested fix.

- **Output path `<design-dir>/.reviews/LINT-<NNN>.md`**: PASS — `.reviews/`
