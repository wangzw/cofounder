## Checklist

This file is a standalone bash lint script (CR-X6 enforcer). Applicable CRs:
CR-X6 (dependency-layering-forward-only, the check this script implements),
plus general script-quality checks: pure-bash requirement, set -euo pipefail,
correct exit codes, correct output path, CLI flag support.

- **Pure bash (`#!/usr/bin/env bash`)**: PASS — shebang is `#!/usr/bin/env bash`;
  no python3 or other interpreter invocations. All logic uses bash builtins,
  `grep`, `sed`, `awk`, `sort`, `printf`, `find`, `mktemp`, `expr`. `awk` is used
  for column-index extraction from pipe-delimited table rows (BSD/GNU compatible).

- **`set -euo pipefail` present**: PASS — declared at line 55 (after the comment
  header block), before any logic executes.

- **Exit codes correct**: PASS — exit 0 (no findings or no modules to check),
  exit 1 (at least one blocker finding, or any finding with --strict), exit 2
  (usage/env error). Verified by smoke tests 1–10: no-args → 2, nonexistent-dir
  → 2, reverse-import → 1, same-layer undocumented → 1, same-layer exempted → 0,
  missing-from-table → 1, clean design → 0.

- **Check A (blocker): reverse-layer import**: PASS — for each (caller, callee)
  dep pair, the script compares `MOD_TO_LAYER[caller]` vs `MOD_TO_LAYER[callee]`.
  If `callee_layer > caller_layer` → emits `reverse_import` LINT-NNN.md with
  severity=blocker, CR-id=CR-X6. Verified: smoke test 3 — M-001 (layer 1) imports
  M-003 (layer 3) → LINT-001.md emitted, exit 1.

- **Check B (blocker): same-layer dep without cross-cutting exemption**: PASS —
  if `callee_layer == caller_layer`, the script calls `_has_crosscutting_exemption`
  which searches (a) the Dependency Layering section text for "cross-cutting" or
  "consumer-side interface" near either module ID, and (b) the caller module's
  Deps section text for the same strings. If neither matches → emits `same_layer`
  LINT-NNN.md (severity=blocker). Verified: smoke test 4 — M-001 same-layer dep
  on M-002, no exemption text → LINT-001.md, exit 1.

- **Check B exemption path**: PASS — when the README Dependency Layering section
  contains "cross-cutting" near the relevant module IDs, `_has_crosscutting_exemption`
  returns 0 (exempt) and no LINT file is emitted. Verified: smoke test 5 — README
  has "Cross-cutting note: M-001 depends on M-002 via consumer-side interface"
  → PASS, exit 0. Smoke test 10 — exemption in caller Deps cell ("consumer-side
  interface") → PASS, exit 0.

- **Check C (blocker): module missing from Dependency Layering table**: PASS —
  if either caller or callee has no entry in `MOD_TO_LAYER`, the script emits a
  `missing_from_table` LINT-NNN.md (severity=blocker). A per-module dedup flag
  (`MISSING_FLAGGED`) ensures only one issue per missing module regardless of how
  many dep pairs reference it. Verified: smoke test 6 — M-002 missing from table,
  referenced by both M-002 (as caller) and M-003 (as callee) → one LINT-001.md,
  exit 1.

- **Forward-only dep (OK path)**: PASS — if `callee_layer < caller_layer`,
  no action taken (the pair is valid). Verified: smoke test 7 — 4-module design
  with layers Types (1) → Repository (2) → Service (3) → UI (4), all deps
  forward-only → PASS, exit 0.

- **Layer number assignment (row-order 1-indexed)**: PASS — `awk` parses the
  Dependency Layering table row by row; a `_layer_row` counter increments on each
  data row containing M-NNN tokens. The first data row = layer 1, second = layer 2,
  etc. Layer label is extracted from column 1 for display in LINT messages.
  Separator rows (matching `^\|[-: |]+\|`) and header rows (matching `\bLayer\b`)
  are skipped.

- **Deps section detection**: PASS — `awk` matches headings
